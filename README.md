Breast Cancer Diagnosis Using Machine Learning

Overview:
This project implements a supervised machine learning pipeline to classify breast tumors as malignant or benign using the Wisconsin Diagnostic Breast Cancer dataset. Multiple classical machine learning models were trained and evaluated.

Dataset:
- 569 samples, 30 numerical features
- Target classes: Malignant (0), Benign (1)
- No missing values

Models Used:
Naive Bayes, K-Nearest Neighbors (KNN), Decision Tree, Random Forest, Support Vector Machine (SVM), Logistic Regression, Neural Network (MLP)

Evaluation:
Metrics: Accuracy, Precision, Recall
Recall is emphasized due to the medical importance of detecting malignant cases.

Results (Test Accuracy):
Naive Bayes: 93%
KNN: 98%
Decision Tree: 95%
Random Forest: 95%
SVM: 96%
Logistic Regression: 96%
ANN (MLP): 97%

How to Run:
Install required packages:
pip install numpy scikit-learn matplotlib
Then run the notebook or Python scripts to reproduce results.
